# 상단바 이전 디자인 시안 정리

작성일: 2026-10-09
대상 유저층: 20대 남성
기준 화면: 대시보드 달력 화면

## 1. 요구 사항

### 1차 요구 사항

- 좌측 사이드바를 모두 상단으로 이동
- 화면 상단은 `docs/design-preview-ko.html` 디자인 참고
  - 단, 예산 주의 표시는 현 디자인(`src/components/calendar/hero-sidebar.tsx` 진행률 로직)을 따름
  - 디자인 참고는 오로지 상단바에만 적용, 본문·우측 패널은 원본 유지
- 시안 3종
  - 1종: 원본에서 지시 사항대로 수정만 한 상태
  - 2종: 색감만 약간씩 수정

### 2차 요구 사항 (A안 개정)

- A안 상단에서 예산 주의 표시 제거
- A안 상단에서 지출 등록 제거, 본문 우상단으로 복귀
- 상단 탭 명칭 변경
  - 홈 대시보드 → 홈
  - 가계부 내역 → 기록
  - 게임 일정 → 게임
- 로그아웃은 계정 탭 클릭 시 드롭다운으로 표시
- 설정 탭은 계정 오른쪽으로 배치

## 2. 상단바 기준 스펙

참고 출처: `docs/design-preview-ko.html:131-165`

- `position: sticky`, `min-height: 64px`
- 구성: 브랜드 | 내비게이션 | 툴바(우측 정렬)
- 내비게이션 버튼: `min-height: 40px`, `border-radius: 9px`, active는 `surface-2` 배경
- 툴바 버튼: `min-height: 40px`, `border-radius: 9px`, `surface-2` 배경

A안 개정 이후 상단 구조:

```text
[ChronoLedger] [홈] [기록] [게임] ...... [테마] [계정 ▾] [⚙️ 설정]
                                              └ 클릭 시 [로그아웃]
```

본문 구조:

```text
[설명 문구] .................... [지출 등록]
[2026년 10월 달력 ............] [요약 / 스토어 포인트 / 일자 상세]
```

## 4. A안 개정 상세

파일: `docs/design-topbar-A-original.html:44-56`

- 내비게이션: `홈`, `기록`, `게임` 3개만 표시
- 툴바 순서: 테마 전환 → 계정 ▾ → ⚙️ 설정
- 계정은 `details/summary` 드롭다운, 내부에 로그아웃 버튼 1개
- 상단 예산 표시 삭제
- 상단 지출 등록 삭제, `.top-actions` 본문 우상단에 `button.primary`로 배치
- 빈 상태 문구에서 "상단의" 삭제: "지출 등록으로 추가할 수 있습니다."
- 모바일(`max-width: 900px`): 달력·사이드 1열, `.top-actions` 세로 배치

## 5. 실제 적용 시 메모

- 적용 대상: `src/app/dashboard/layout.tsx:68-102`
  - 데스크톱 좌측 `aside` 제거 후 상단 `header`로 이동 필요
  - 기존 `navItems` 라벨 변경 필요: `홈 대시보드→홈`, `가계부 내역→기록`, `게임 일정→게임`, `설정`은 툴바 영역으로 분리
  - 로그아웃 단독 버튼 제거 후 계정 드롭다운 메뉴로 이동 필요
  - 모바일 상단바·메뉴(`layout.tsx:70-81`)와 중복 정리 필요
- 예산 경고 로직은 현행 유지: `HeroSidebar`의 `budgetRatio > 1 → danger`, `>= 0.8 → warning`, 그 외 `primary`
- 본 시안은 정적 HTML 목업이며, 실제 데이터 연동·반응형·접근성은 별도 구현 필요

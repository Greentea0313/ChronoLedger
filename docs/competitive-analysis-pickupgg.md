# 경쟁 서비스 비교: 픽업지지(pickupgg.com) vs ChronoLedger

- 작성일: 2026-11-09
- 조사 방법: pickupgg.com 비로그인 상태로 홈(리스트형·캘린더형·월정액/패스), 게임별 일정(`/game/genshin`), 파티 시뮬레이터(`/party`), 건의·공지(`/notice`) 직접 확인함. 로그인 후 기능(월정액 기록, 서버 저장 등)은 화면 안내 문구 기준으로 추정함.
- ChronoLedger 기준: `main` `a63fc4f` 시점 `docs/spec/SRS.md`, `docs/spec/SPEC.md`, `docs/to-do.md`, `src/` 구조 기준임.

## 3. ChronoLedger만의 강점

- **일정 ↔ 지출 결합**: 픽업지지는 "언제 무엇이 나오는가"까지만 다룸. ChronoLedger는 일정에 예정 지출을 묶고, 일정 날짜 변경 시 `PLANNED` 지출 자동 동기화(DB 트리거)함 → "이번 픽업에 얼마 쓸 예정인가"까지 관리 가능함.
- **예산 관리**: 월 예산·기본 예산, 예상 소비액 80%/100% 경고, 초과 시 저장 전 확인함. 픽업지지에는 금액 개념 자체가 없음.
- **스토어 포인트 지갑**: Google Play 등급별 적립률, Galaxy Store 등급, 네이버페이 1만원 단위 충전까지 반영한 결제·환불 원자 트랜잭션임. 국내 모바일 과금 유저 특화 기능으로 대체재 거의 없음.
- **정기 구독(월정액·패스) 자동 회차 생성**: 픽업지지 월정액·패스는 잔여일 표시 위주임. ChronoLedger는 `MONTHLY_DAY`/`INTERVAL_30`/`VERSION_PASS`로 실제 지출 회차를 생성해 예산에 반영함.
- **과금 통계**: 카테고리·게임별 확정 지출 차트, 월별 비교 제공함 → 과금 회고·절제 도구로 기능함.
- **데이터 무결성·보안**: RLS 소유자 격리, 금액 계산 서버 RPC, 지출 물리 삭제 금지, 환불 롤백 보장 등 금융 원장 수준 설계임.
- **개인화 데이터**: 날짜별 개인 메모, 게임별 상시 메모, 비공개 커스텀 아이콘, 캘린더 배경 커스터마이징 제공함.
- **멀티 플랫폼**: PWA 오프라인 읽기 캐시, Tauri 데스크톱(예정)으로 앱 형태 사용 가능함.
- **사용자 참여형 카탈로그**: 게임/일정 추가 요청 → 관리자 승인 구조라 운영자 1인 큐레이션 한계를 일부 분산 가능함.

## 4. 개선점 (픽업지지 대비 부족한 부분)

### 4.1 우선순위 높음

- **일정 분류 세분화**: 현재 `VERSION`/`PICKUP`/`CONTENTS` 3종뿐임. 픽업지지는 픽업 내 신규/복각 구분, 특별방송, 업데이트, 오프라인 행사까지 분류함.
  - 제안: `PICKUP`에 `is_rerun`(복각) 플래그 추가, `BROADCAST`(특별방송) 일정 종류 추가 검토. 특별방송은 다음 버전 과금 계획 수립의 핵심 시점이라 지출 계획과 시너지 큼.
- **오늘/이번 주 요약**: 픽업지지는 상단에 "오늘 일정 N건 / 오늘 마감" 배지, 리스트형에 "이번 주" 강조 제공함. ChronoLedger는 월 캘린더 + 선택일 상세 구조라 한눈에 보기 약함.
  - 제안: 대시보드 상단에 오늘 시작/마감 일정 + 이번 주 예정 지출 합계 요약 카드 추가함.
- **D-day·진행률 표시**: 픽업지지 ON AIR 배너의 "D-15 종료" + 진행 바가 직관적임.
  - 제안: 사이드바 일정 카드와 예정 지출 카드에 종료 D-n, 기간 진행률 표시함. 예정 지출의 결제 마감 체감 효과 큼.
- **리스트형(주차별) 보기**: 모바일에서 월 캘린더는 정보 밀도가 낮음. 주차별 목록 뷰 토글 추가 검토함.

### 4.2 우선순위 중간

- **관심(즐겨찾기) 일정**: 하트 → 관심 모음 → "관심만" 필터 흐름이 단순·강력함. ChronoLedger의 게임 단위 필터보다 세밀함. 관심 픽업에서 바로 "예정 지출 추가" 연결 시 차별화 가능함.
- **게임별 상세 페이지**: 현재 게임 관리 화면의 일정 보기 모달은 미래 일정 목록 수준임. 픽업지지처럼 진행 중 / 다음 예정 / 지난 기록(최근 6개월)을 구분하고, ChronoLedger 고유 데이터인 **해당 게임 누적 과금·픽업별 지출**을 같은 페이지에 결합하면 강한 차별점이 됨.
- **일정 시각 정보**: 픽업지지는 "16:00", "점검 후(12:00 예상)" 등 시각·예상 여부 표기함. 현재 스키마는 DATE만 관리함 → `start_time`·`is_estimated` 같은 표시용 필드 검토함.
- **온보딩**: 신규 가입 시 게임 구독이 비어 있음. 첫 진입 시 게임 일괄 선택 팝업 추가하면 첫 화면 공백 해소됨.
- **내 게임 순서 변경**: 픽업지지는 내 게임 드래그 정렬 지원함. 현재 캘린더 아이콘은 가나다순 고정임.

### 4.3 우선순위 낮음 / 장기

- **R13 캐릭터·프리셋 마무리 시 참고점**: 픽업지지 파티 시뮬레이터는 보유/미보유 집계, 속성 필터, 엔드 콘텐츠별 편성(팀 수 제한·중복 불가)까지 제공함. R13 13.3은 보유 체크·프리셋 저장까지라, "콘텐츠별 편성 + 중복 금지" 기능은 후속 확장 후보로 기록 필요함. 반대로 ChronoLedger는 캐릭터별 메모·비공개 커스텀 아이콘·관리자 승인 카탈로그가 차별점임.
- **비로그인 체험**: 픽업지지는 로그인 없이 일정 조회·파티 편집 가능함(로컬 저장). ChronoLedger는 개인 재무 앱 특성상 로그인 필수가 타당하나, 공용 일정 미리보기 정도의 공개 랜딩 페이지는 유입에 유리함.
- **건의·공지 채널**: 현재 게임/일정 요청만 있음. 일반 건의·공지 기능은 사용자 규모가 생긴 뒤 검토함.
- **알림**: 양쪽 모두 푸시 알림 확인되지 않음. PWA/Tauri 기반이라 "픽업 종료 D-1", "예정 지출 결제일" 알림을 먼저 제공하면 선점 가능함.

## 5. 포지셔닝 정리

- 픽업지지 = **서브컬처 게임 일정 정보 포털**(넓은 게임 커버리지, 운영자 큐레이션, 빠른 조회).
- ChronoLedger = **게임 일정 기반 개인 과금 가계부**(일정 → 예정 지출 → 결제·포인트 → 통계까지 닫힌 루프).
- 일정 정보량·탐색 UX로 정면 경쟁하기보다, 일정 표시는 픽업지지 수준의 가독성(D-day, 오늘 요약, 복각 구분)을 따라잡고 **"이 픽업에 얼마 쓸지, 썼는지"** 를 핵심 가치로 강조하는 방향이 적합함.

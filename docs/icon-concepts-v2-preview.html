추천 · 계승 정제형

시안 1 — C-Chrono + 메모 도트

임시 아이콘 수정 방향. Chrono의 C + 시곗바늘은 유지하고, C가 열린 틈에 메모 1도트를 배치해 캘린더 타일 언어(아이콘+도트)를 담았습니다.

단점: 가계부·예산 속성은 여전히 은유적
본질 직관형

시안 2 — 캘린더 + ₩ 코인

완전 신규. 월간 캘린더(VERSION/PICKUP 배너바 2개)에 골드 ₩ 코인을 겹쳐 일정-지출 연결이라는 제품 본질(SRS §1)을 직접 표현. ₩는 폰트가 아닌 벡터 스트로크로 그려 축소·기종 의존성 제거.

기획 연결: Calendar-first(시트 §1.1) + FR-010 VERSION/PICKUP 2종(배너 2색) + 정수 KRW(SRS §3).
토큰: 바탕 #171A21 / 헤더 #5365D4(primary light) / 배너 #65A9FF·#4CD6A5 / 코인 #F5B942
장점: 첫인상에서 하는 일이 보임 · 스토어·공유 썸네일용 존재감
단점: 16px에서 ₩ 획 뭉개짐(코인 실루엣으로 커버) · 요소 수 최다
차별화형

시안 3 — 원장 + 예산 게이지

완전 신규. 펼친 원장 위에 일정 배너 2개와 예산 게이지(82% 주의·100% 초과 위험)를 배치해 히어로 사이드바의 예산 게이지(FR-022)를 아이콘에 새겼습니다. 앱 서랍에서 가장 눈에 띕니다.

단점: 게임·시간 속성이 약함 · 다크 테마 앱 목록에서 상대적으로 튐
총평: 파비콘·작업표시줄·마스크블 대응과 기존 연속성을 중시하면 시안 1이 무난합니다. 제품의 "일정+지출" 본질을 아이콘에서 말하게 하려면 시안 2, 예산·원장 이미지를 앞세워 스토어/PWA 설치 화면에서 눈에 띄게 하려면 시안 3입니다. 어느 안을 고르든 다음 단계는 동일합니다: 선택안으로 scripts/generate_icons.py를 확장해 public/icons/icon-{512,192,180,maskable-512}.png 4종을 재생성하고 public/manifest.json·애플터치 연결을 검증합니다.

# 프로젝트 문서 저장 원칙 (Project Document Location Rule - 한국어 원본 아카이브)

> **보관 안내**: 본 문서는 Phase 12.22 지침 영문화 이전의 한국어 원본입니다. 최신 활성 지침은 `.agents/rules/document_location.md`를 참조하세요.

- **프로젝트 관련 문서는 항상 프로젝트 내부 경로에 저장합니다.**
  - 기획서, 설계서, 진행 상황, 가이드 등 특정 프로젝트에 국한된 문서는 Antigravity 세션 임시 아티팩트 디렉터리(`brain/...`)가 아닌 프로젝트 내부 문서 디렉터리(`docs/`)에 우선 저장합니다.
  - Git 버전 관리가 가능하도록 프로젝트 작업 공간 내에 명확히 위치시켜야 합니다.

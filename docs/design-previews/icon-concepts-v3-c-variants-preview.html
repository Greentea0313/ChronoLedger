시안 1(C-Chrono) 기반 변형 3종 (v3)

파일: docs/icon-concepts-v3-c-variants-preview.html — 브라우저로 직접 연 파일입니다.
공통 뼈대: v2 시안 1의 C-링 + 시곗바늘 지오메트리(토큰 색 #F5B942/#7C8CFF, 바탕 #0F1115). 3종은 "같은 C, 다른 액센트" 변형입니다 — C의 열린 틈·하단에 무엇을 두느냐가 차이점입니다. 전 시안 마스커블 80% 안전영역 준수, 축소 테스트(48/32/16px) + 라이트 배경 테스트 포함, <text> 미사용.

기준안

시안 1A — C + 메모 도트 (v2-1 유지)

비교 기준. C 틈에 성공색 메모 1도트(FR-071 타일 언어). 요소 최소, 소형 가독성 최상.

액센트: 틈새 메모 도트 #4CD6A5
장점: 16px·파비콘 가독성 최상 · 기존 임시 아이콘과 연속성
단점: 가계부 속성은 은유적(도트 서사를 알아야 읽힘)
원장 게이지형

시안 1B — C + 예산 바

C를 86%로 축소·상단 배치하고 하단에 예산 바(82% 주의 채움, FR-022) 추가. 시간(Chrono) + 예산(Ledger) 이중 서사. 바는 축소 시 베이스라인으로 읽힙니다.

48px
32px
16px
액센트: 하단 예산 바 — 트랙 #2A2F3A + 82% 채움 #F5B942(230/280)
장점: 3종 중 원장·예산 서사 최강 · 바가 소형에서도 실루엣 유지
단점: C 축소로 16px 시계 디테일 약화 · 요소 수 최다(16px는 도트 생략형)
코인형

시안 1C — C + ₩ 미니코인

틈새 도트 자리에 골드 미니코인(벡터 ₩)을 품은 C. "일정 사이사이의 지출"이라는 은유. 대형에서 개성이 가장 강합니다.

48px
32px
16px
액센트: 틈새 미니코인 #F5B942 + 벡터 ₩ 스트로크(16px는 코인만)
장점: 대형(스토어·스플래시) 개성 최상 · 돈 속성 직접 표현
단점: 16px에서 코인이 C링과 붙어 보여 두께로 읽힘 · ₩ 획은 48px부터 식별
총평: 안전 선택은 1A(소형 가독성·연속성), 원장 의미를 C 틀 안에서 가장 강하게 넣은 안은 1B, 대형 노출용 개성은 1C입니다. 1B·1C의 소형 리스크는 16px생략형(도트/₩ 획 제거)으로 완화해 두었습니다. 선택안이 정해지면 해당 안으로 scripts/generate_icons.py를 확장해 public/icons/icon-{512,192,180,maskable-512}.png 4종을 재생성하고 public/manifest.json 연결을 검증합니다.

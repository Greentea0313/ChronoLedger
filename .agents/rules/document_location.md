# Project Document Location & Style Rule

- **Always store project-related documentation within the project repository.**
  - Specifications, design notes, progress updates, guidelines, and project-specific documents must be stored inside the project `docs/` directory, never in external temporary session directories (e.g. `brain/...`).
  - Keep documentation properly located inside the workspace to ensure full Git version tracking.
- **문서 작성 스타일 (개조식 준수)**:
  - **답과 문서는 한국어 개조식(~함, ~임)으로 쓸 것.**
  - 프로젝트 운영 문서(진행상황, 변경이력, 인수인계 등)는 명확하고 간결한 개조식 종결어미(`~함`, `~임`, `~됨` 등)를 일관되게 사용함 (기계 판독용 아티팩트 및 영문 명세서는 기존 영문 규격 유지).

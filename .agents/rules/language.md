# 한국어 소통 원칙 (Korean Language Rule)

*   **항상 한국어로 대답하세요.** (Always respond in Korean.)
*   사용자에게 팝업 질문을 띄울 때(`ask_question` 도구 사용 시), **질문(question)과 선택지(options)는 반드시 한국어로 작성**해야 합니다.
*   코드 주석이나 커밋 메시지 등 명시적으로 영어가 요구되는 경우를 제외한 모든 대화와 설명은 한국어로 진행합니다.
